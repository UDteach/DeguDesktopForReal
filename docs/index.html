HOW IT WORKS

いつもの画面に、
小さなサプライズ。

01

たまに現れる

下から顔を出す、端からのぞく、跳び込む。3つの短い動きをランダムに再生します。

02

壁紙はそのまま

透明なウィンドウを重ねる方式。今の壁紙やデスクトップの配置を変えません。

03

好きな毛色を選べる

1色だけ、複数色からランダム、全色ランダム。出現間隔とサイズもメニューから選べます。
