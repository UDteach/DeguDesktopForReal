MAC の初回起動

「マルウェアが含まれていないことを検証できません」と表示されたら

Mac 版は Apple の Developer ID 署名・公証をしていないため、初回起動時にこの警告が出ることがあります。このページから入手したアプリを開く場合は、次の手順で許可してください。

  1. DMG からアプリをインストール

    ダウンロードした DMG を開き、「Degu Desktop for Real」を「アプリケーション」フォルダへドラッグします。

  2. アプリを一度開く

    「アプリケーション」フォルダからアプリを開きます。警告が出たら、そのダイアログを閉じます。

  3. 設定画面の「このまま開く」を選ぶ

    macOS 13 以降Apple メニュー →「システム設定」→「プライバシーとセキュリティ」。下部の「セキュリティ」までスクロールし、「Degu Desktop for Real がブロックされました」という項目の「このまま開く」を選びます。

    macOS 12 MontereyApple メニュー →「システム環境設定」→「セキュリティとプライバシー」→「一般」→「このまま開く」を選びます。

  4. 確認ダイアログで開き、認証する

    もう一度「このまま開く」（macOS によっては「開く」）を選びます。認証を求められたら、Mac の管理者名とパスワードを入力して「OK」を押します。

起動後はメニューバーへ。画面上部の肉球アイコンから「今すぐ表示」や設定を選べます。Dock にアイコンは表示されません。

「このまま開く」が見つからない場合は、手順 2 でアプリを開く操作をもう一度行ってから、設定画面に戻ってください。

「壊れているため開けません」は別のエラーです。v0.6.1 をお使いなら、このページの最新版に入れ替えてください。

Mac の種類が分からないとき

画面左上の Apple メニューから「この Mac について」を開き、「チップ」または「プロセッサ」を確認してください。Intel と表示されれば Intel Mac 版、M1 などと表示されれば M1 以降の Mac 版を選びます。

Windows のインストール

ダウンロードした EXE を実行してください。インストールせずに使う場合は ZIP 形式を選べます。

更新履歴・過去の版・その他の形式は GitHub Releases をご覧ください。
