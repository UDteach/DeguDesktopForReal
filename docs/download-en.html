FIRST LAUNCH ON MAC

If Apple cannot check the app for malicious software

The Mac app has no Apple Developer ID signature or notarization, so macOS may show this warning the first time you open it. If you downloaded it from this page, you can allow this app with these steps.

  1. Install the app from the DMG

    Open the downloaded DMG and drag Degu Desktop for Real to Applications.

  2. Try opening the app once

    Open it from Applications. If the warning appears, close the alert.

  3. Choose Open Anyway in settings

    macOS 13 or laterApple menu → System Settings → Privacy & Security. Scroll down to Security, find the message that Degu Desktop for Real was blocked, and choose Open Anyway beside it.

    macOS 12 MontereyApple menu → System Preferences → Security & Privacy → General → Open Anyway.

  4. Confirm opening and authenticate

    In the next dialog, choose Open Anyway (or Open, depending on your macOS version). If prompted, enter your Mac administrator name and password, then choose OK.

After launch, look in the menu bar. Use the paw icon at the top of the screen for Show now and settings. The app does not show an icon in the Dock.

If Open Anyway is missing, try opening the app again as in step 2, then return to settings.

“The app is damaged” is a different error. If you have v0.6.1, replace it with v0.6.2.

Read Apple’s instructions ↗

Not sure which Mac you have?

Open the Apple menu at the top left and choose About This Mac. Look for “Chip” or “Processor.” If you see Intel, choose Intel Mac. If you see M1 or another M-series chip, choose M1 or later Mac.

Install on Windows

Run the downloaded EXE. Choose the ZIP if you want to use it without an installer.
