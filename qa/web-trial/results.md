# Webでおためし — 確認結果

2026-09-27。基準コミット `a0504f3`、ブランチ `codex/web-trial`。
macOS / Node.js 24 / Playwright Chromium、ローカル `http://127.0.0.1:4175/` で実施。

| 確認 | 結果 |
| --- | --- |
| 入口 | 日英トップ・ダウンロードの4ページで320pxのヘッダーに体験リンクが見える。クリック後に対応言語の体験ページへ移動し、動画が再生される。トップの主ボタン、ダウンロードの導入にも同じ行き先を設置。 |
| デグーの選択 | おまかせ＋16毛色を表示。バイオレットパイドとアグーチを選択し、指定した動画の再生を確認。種の選択欄は省いた。 |
| 設定 | 間隔・大きさ・背景・毛色を変更し、再読み込み後も保持。一時停止中の設定変更は自動再生しない。 |
| 全画面 | ネイティブ全画面への切り替え・解除、3.5秒後の操作部非表示、マウスとTabによる復帰を確認。拡大中は画面外の設定がinertになり、解除後に戻る。 |
| 全画面非対応・拒否 | API無効と拒否を模擬し、ページ内拡大になることを確認。Escと戻るボタンで解除できる。 |
| レスポンシブ | 体験画面は1440 / 390 / 320pxで横スクロール・ボタンのはみ出しなし。日英ホーム・英語DLも601 / 768 / 900 / 1024 / 1440pxでヘッダーやページのはみ出しなし。 |
| 読み込み失敗 | 動画404は同じ毛色のPNGに切り替えて案内。動画とPNGの両方404は失敗を表示し、通信回復後は次回予定時刻に動画が再生される。画像のメモリキャッシュを避け、両方失敗の検査は新規読み込みで実施。 |
| 保存不可 | 壊れたJSONは初期値に戻る。Storage APIが読み書きとも失敗しても再生・毛色選択できる。OBSとは保存キーを分離。 |
| タブ・動きの設定 | visibilitychangeで停止・復帰し、手動一時停止は維持する。reduced-motionでは停止して開始し、今すぐ表示から再生できる。 |
| モジュール失敗 | カタログが404でも読み込み失敗メッセージと公式サイトへ戻るリンクを表示。 |
| OBS回帰 | 設定画面のプレビューと発行URLの動画が再生され、出力ページの背景は `rgba(0, 0, 0, 0)`。 |
| 自動チェック | `npm run check:obs` 8件、`npm test` 全18件が合格。`node --check web/try/trial.mjs`、生成物一致・参照先検査、`git diff --check` も合格。 |
| 通常操作のエラー | ページエラー・コンソールエラーとも0件。異常系の検査では意図的な404のみ発生。 |

画像は `docs/design/evidence/after/trial-*.png` に保存。Animals版の参照と比較し、表示面の優先順位、操作の位置、背景、文字サイズを維持。デグーの緑系配色と4項目の設定が意図した差分。320pxのダウンロード見出しで末尾1文字が改行される点を修正し、再撮影した。未解決の表示差はない。

コピー確認: 日本語主体、既存の丁寧な距離感、1文1動作、主導線は「Webでおためし」、内部用語や品質の自称を表示しない。英語も同じ操作順。ブラウザ内表示とアプリでのデスクトップ表示の違いを案内する。

未実施: Safari / iOS / Android / Windows実機、OBS Studio実機、長時間連続再生。スマホ幅はChromiumのビューポートで確認した。
